# SplitMoney

A responsive trip expense sharing app. Create a group, add friends by name, record expenses, choose who shares each cost, and see balances update automatically.

## Use it

Open the [SplitMoney site](https://deepakray184.github.io/SplitMoney/), set your name by clicking your profile, create a group, and add friends using comma-separated names. Use **Add an expense** to choose a payer and tick the people who share the cost. The amount is split equally, with any leftover cents distributed one at a time.

Groups and expenses are saved in this browser using local storage. The current GitHub Pages version has no accounts or shared server, so different devices do not see each other's updates.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.
