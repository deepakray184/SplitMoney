# SplitMoney

A responsive trip expense sharing web app inspired by Splitwise. Track shared group expenses, see who owes whom, add expenses, and record repayments.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## GitHub Pages

This repository is configured to serve the static app from the `main` branch root. The current interface uses sample data; added expenses and settlements are held in the page state and are not synced or saved to a backend.
